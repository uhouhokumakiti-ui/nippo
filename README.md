# 試錐日報アプリ（PWA）

ボーリング現場の試錐日報をスマホで入力し、会社の日報様式（A4横）のPDFにして、LINE WORKSなどで送るアプリです。
データはそれぞれのスマホの中だけに保存され、サーバーには送られません。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・入力・帳票・PDF作成） |
| `sw.js` | サービスワーカー（電波がなくても起動できるようにする） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ名・アイコン |
| `icons/` | アイコン画像 |
| `lib/` | PDF作成用のライブラリ（html2canvas 1.4.1、jsPDF 2.5.1）と、XMLをShift_JISで書き出すためのライブラリ（encoding-japanese 2.0.0） |

## GitHub Pagesに置く手順

1. GitHubにログインして、右上の「＋」→「New repository」で新しいリポジトリを作ります（例：`nippo`、Publicを選択）。
2. 作ったリポジトリの画面で「Add file」→「Upload files」を押し、このフォルダの中身（`index.html`、`sw.js`、`manifest.webmanifest`、`icons`フォルダ、`lib`フォルダ）をまとめてドラッグして「Commit changes」を押します。
3. 「Settings」→ 左メニューの「Pages」を開き、「Branch」を `main`、フォルダを `/ (root)` にして「Save」を押します。
4. 1〜2分待つと、`https://（GitHubのユーザー名）.github.io/nippo/` のURLが表示されます。これを作業員さんに配ります。

## スマホへの入れ方（作業員さん向け）

- **iPhone**：SafariでURLを開く →共有ボタン（□に↑）→「ホーム画面に追加」
- **Android**：ChromeでURLを開く → 右上のメニュー（︙）→「ホーム画面に追加」または「アプリをインストール」

ホーム画面に追加せずにブラウザのまま使うと、しばらく開かなかったときにデータが消されることがあります。必ずホーム画面から使ってください。

## アプリを修正したとき

1. 修正したファイルをGitHubにアップロードし直します。
2. `sw.js` の先頭にある `VERSION` の数字を上げます（例：`0.3.0` → `0.3.1`）。`index.html` の `APP_VERSION` も同じにしておくと、画面で版を確認できます。
3. 作業員さんが次に電波のある場所でアプリを開くと「新しいバージョンがあります」と出るので、「更新する」を押すと切り替わります。入力済みのデータはそのまま残ります。

## 使い方の流れ

現場を選ぶ（なければ追加）→ 孔番号を選ぶ（なければ追加）→ 作業日を選ぶ（「閲覧」か「編集」）または「作業日を追加」→ 項目ごとに入力 →「PDFで送る」

- 入力は1文字ごとに自動保存されます。
- 孔ごとに「土砂用／岩盤用」を切り替えられます（作業日一覧の下）。岩盤用では指定深度ごとの掘進速度・給圧・回転数などを記録し、帳票の掘進状況の欄がその記録に変わります。
- 現場の画面の「この現場の週報を作る」から、日曜〜土曜の週報をPDFで作れます。そのスマホに入っている日報から作るので、別のスマホで入力した孔は「データ読み込み」で取り込んでから作ってください。
- 土質は上から順につながる形でしか入力できません。上端は前日の到達深度・前の層の下端で自動的に決まり、翌日の入力では前日の最後の地層がヒントで出ます（「前日の層の続き」を選ぶと柱状図で1層につながります）。つながりが崩れていると、日報・週報・柱状図・XMLは出力できません。
- 孔の画面の「この孔の出力」から、簡易柱状図（A3縦・確認用）のPDFと、柱状図XML（ボーリング交換用データ ver4.00・Shift_JIS）、日報のまとめPDFを出せます。現場の画面からは、現場全体の日報まとめPDFを出せます。
- 作業日ごとに作業区分（通常／雨天中止／待機）を選べます。移動は、その現場で一度入れた区間から選びます。
- 新しい作業日を追加すると、前日の到達深度、現場条件、ケーシング、作業員が引き継がれます。
- 入力ミスの可能性があるところは警告が出ますが、そのまま保存・PDF作成もできます。
- オペレーターが休むときは、孔の「⋯」→「この孔のデータを書き出す」で出したファイルを代わりの人が「データ読み込み」で取り込みます。戻すときも同じ手順で、同じ日の内容が違う場合はどちらを残すか確認が出ます。
